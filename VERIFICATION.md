# Проверка этапа 1 — 2026-11-18

Среда: Linux, .NET SDK 10.0.115. `dotnet build --no-restore` — 0 ошибок, 0 предупреждений.

HTTP-проверки выполнены на Kestrel :8765 с тестовым исполняемым Perl-имитатором Unity вне репозитория. Имитатор получает штатные аргументы Bridge и записывает файл, указанный в -logFile. Это проверяет интеграцию Bridge, 
но не Unity.

Подтверждено:

- `/health`: HTTP 200, доступность настроенных Editor и проекта.
- Защищённый маршрут без токена: HTTP 401.
- Запуск с токеном и `{}`: HTTP 202, GUID и URL состояния/логов.
- Успешный процесс с чистым логом: Succeeded, exitCode 0.
- Лог с `error CS1002` при exitCode 0: Failed, success false, ошибка извлечена.
- `logs?lines=1`: одна последняя строка и truncated true.
- Попытка передать projectPath: INVALID_REQUEST.
- Шесть быстрых запросов: 202, 202, 202, 202, 429, 429 — один активный и три ожидающих.

Не проверено: реальный Windows Unity Editor, лицензия, реальная компиляция HeliWords, доступ host.docker.internal и Firewall, принудительное завершение дерева настоящего Editor. 
Эти проверки требуют запуска Bridge на Windows-хосте. Endpoint отмены и очистка логов ещё не реализованы (этап 4).
